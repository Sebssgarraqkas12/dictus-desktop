### 1. macOS "Dictus quit unexpectedly" dialog absence (SHUT-03)

**Test:** On macOS Sequoia 15.x, with a Phase 7 build installed: (a) launch the app, (b) click tray icon → "Quit Dictus", (c) confirm no "Dictus quit unexpectedly — Reopen / Report / Ignore" dialog appears. Repeat after a forced `simulate_updater_restart` from the Debug Settings panel.

**Expected:** No crash dialog under any path. App terminates cleanly. `Console.app` shows no abort/segfault entries for `dictus` around the quit timestamp.

**Why human:** The crash dialog is an OS-level UI surface that only renders on a physical macOS device with a live windowing session. There is no programmatic API to observe it. Validation is qualitative (dialog appears / does not appear) and required multi-day observation in a normal-use environment.

**Result (recorded 2026-04-23):** Pierre Viviere — macOS Sequoia 15.x, Apple Silicon — multi-day daily-use validation window (2026-04-16 through 2026-04-23). No "Dictus quit unexpectedly" dialog observed across tray-quit and post-relaunch flows. Documented in `07-01-SUMMARY.md` §Accomplishments "Real-world validation" and §Decisions Made item 4.
